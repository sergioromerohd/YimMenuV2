# Translation Files / Archivos de Traducción

## Overview / Resumen

This directory contains translation files for the YimMenu UI.

Este directorio contiene archivos de traducción para la interfaz de YimMenu.

## Status / Estado

⚠️ **Note / Nota:** These translation files are provided as **templates/examples** only. The menu does not currently have a translation system implemented.

Estos archivos de traducción se proporcionan solo como **plantillas/ejemplos**. El menú actualmente no tiene un sistema de traducción implementado.

## Files / Archivos

- `en_US.json` - English (default)
- `es_ES.json` - Español (Spanish)

## Implementation Required / Implementación Requerida

To use these translations, you would need to:

Para usar estas traducciones, necesitarías:

1. Create a translation loader class / Crear una clase cargadora de traducciones
2. Integrate it into the menu system / Integrarla en el sistema de menú  
3. Replace hardcoded strings throughout the codebase / Reemplazar strings codificados en todo el código
4. Add language selector in Settings / Agregar selector de idioma en Configuración

See `TRANSLATION_NOTES.md` in the root directory for more details.

Ver `TRANSLATION_NOTES.md` en el directorio raíz para más detalles.
